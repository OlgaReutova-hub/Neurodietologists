# Нейродиетолог (MVP)

Демо-приложение на Streamlit для подбора типового дневного рациона при снижении веса и визуализации риска дефицита пищевых волокон и железа.

## Что делает приложение

- Позволяет выбрать пол, дневную калорийность и тип питания.
- Показывает готовое меню на день (завтрак, обед, перекус, ужин).
- Отображает оценку дефицита по двум микронутриентам:
  - пищевые волокна;
  - железо.
- Показывает возможные проявления дефицита и итоговое пояснение.
- Открывает памятку для пациента в PDF (в диалоговом окне) с возможностью скачать файл.

## Технологии

- Python
- Streamlit
- JSON (источник данных сценариев)

## Структура проекта

- `app.py` — основной Streamlit-интерфейс.
- `data/menus.json` — сценарии меню и расчетные показатели дефицитов.
- `Vash-racion-pri-snizhenii-vesa*.pdf` — памятка для пациента.

## Быстрый запуск

1. Откройте терминал в папке проекта:

```powershell
cd "C:\Users\Asus\Desktop\Курсор\Фибраксин и Ассистент диетолога"
```

2. (Рекомендуется) создайте и активируйте виртуальное окружение:

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
```

3. Установите зависимости:

```powershell
pip install -r requirements.txt
```

4. Запустите приложение:

```powershell
streamlit run app.py
```

После запуска откроется локальная страница Streamlit (обычно `http://localhost:8501`).

## Параметры в интерфейсе

- Пол: `Женщина` / `Мужчина`
- Дневная калорийность: `1200`, `1300`, `1400`, `1500` ккал
- Тип питания:
  - `Офисное меню`
  - `Домашнее меню`
  - `Перекус в городе`

## Формат данных

Файл `data/menus.json` содержит массив `scenarios`. Для каждого сценария задаются:

- `kcal`, `meal_type`, `meal_type_label`;
- `meals` (приемы пищи по категориям);
- `deficits` (проценты и цветовой индикатор по полу);
- `symptoms` (возможные проявления);
- `summary` (текст для пользователя отдельно для `female`/`male`).

Логика цвета индикатора:

- `green` — дефицит < 20%
- `yellow` — дефицит 20-39%
- `red` — дефицит >= 40%

## Важные замечания

- Путь к PDF-памятке в `app.py` теперь относительный: приложение автоматически ищет файл по шаблону `Vash-racion-pri-snizhenii-vesa*.pdf` в корне проекта.
- Приложение использует демонстрационные сценарии из JSON и не является медицинской консультацией.
